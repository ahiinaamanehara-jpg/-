作成日：2026-10-29。照合対象：`5de4ff8`。**設計の具体化であり、講座や共有制限の実装ではない。**

## 3. 必要な追加を小さくまとめる

既存の道具を再実装する必要はない。基本講座に新しく必要なのは次の五つ。

1. **講座の入口と工程の枠**：講座モードと自由モードを切り替える。
2. **正面顔6工程の教材**：短文・汎用の図解・お手本・小課題を用意する。
3. **3段階の支援**：必要な詳しさだけを開く。
4. **講座の進行と観察の記録**：作品の保存に結び付けて再開する。
5. **工程結果の独立保存**：あとから描き足しても、以前の記録を残す。

工程比較・応用候補はこれらの後に足す提案。レイヤー、5方向、拡縮回転などは使いたいときの補助として残し、講座開始時に全部を選ばせない。生成AI相談は上記五つの前提ではない。

別に、2026-10-30の回答で**教材そのものと、教材をなぞった作品もアプリ内だけで使う方針**が確定した（D10）。教材の画素をPNGから除くだけでは足りず、線だけのPNG・端末共有も対象から外す。なぞっていない本人の作品のPNG出力は残す設計。作品の利用範囲の識別・継承、画像取込、個人用ZIPの例外、旧作品の扱いは[教材の取扱い](MATERIAL_HANDLING.md)で具体化する。制限は未実装。

## 4. 実装前の順序

1. 教材となぞった作品をアプリ内だけにする決定（D10）を前提に、個人用ZIPの例外（D11）と識別・旧作品・取込の扱い（D12）を決める。出力制御は講座の有無によらず共通で適用する設計とする。
2. C1で既存制作画面への講座の付け方を作る。自由創作を残し、教材の枠でCanvasを作り直さない。
3. C2で教材・観察・3段階ヒントを作る。汎用のお手本と現在のあたり素材の出典を分ける。
4. C3で講座・工程画像・ZIP・削除を整合させる。教材の方針と矛盾する「全データ」という表示を作らない。
5. C4で比較・応用・取込と講座の関連をつなぎ、C5で初心者の体験を検証する。

今回は引き当てと設計の更新まで。C1の実装、画像の削除、既存のPNG／ZIP機能の停止は行わない。
