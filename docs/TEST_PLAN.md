# 動作確認と受け入れ基準

## 現在の状況

M1・M2の自動検証を実施済み。M2の実機画像選択・操作は確認待ち。M3以降の未実装部分と読み上げ確認は未実行。

## 検証方法

- 単体：候補・質問選択、入力検証、revision、バックアップ形式。
- 結合：実ブラウザーのIndexedDBで保存・復帰・トランザクション失敗・移行・関連削除を確認。モックだけで保存成功としない。
- E2E：Playwrightで主要フローと静的ビルドを確認。描画後の画素、消しゴム、保存前後の画像内容も確認し、スクリーンショットだけに依存しない。
- 手動：実機の描画感、取込、回転、ソフトキーボード、書出、読み上げ。端末エミュレーションを実機確認の代わりにしない。

## アクセシビリティと表示

キーボードでフォーム・テーマ・道具・保存・取込・ギャラリー・データ管理を操作する。フォーカス順、見えるフォーカス、Escape、ダイアログの保持と復帰を確認。VoiceOverまたはTalkBackでラベル・エラー・保存通知を確認する。自由描画はポインター前提という制約を明記する。

320／375／390／768／1280px幅、縦横回転、200%拡大、ソフトキーボード表示で重要操作が使えること。通常文字4.5:1以上などのコントラスト、色以外の状態表示、原則44px以上の操作領域を確認する。意味や文言は手動レビューする。

## 端末・性能

iOS SafariとAndroid Chrome各1台以上、および対象PCブラウザーで必須フローを確認し、機種とバージョンを記録する。利用できない端末は未実行。HTTPS静的配信・サブパス・直接URL再読込も確認する。

M4で基準端末を決め、連続5分描画、20操作の取消、回転、保存復帰でクラッシュ・線の欠落がないことを必須とする。入力から反映まで95パーセンタイル50ms以内を暫定目標として計測する。960px作品50件の一覧で原寸画像を全件同時デコードせず、サムネイルを使う。バックアップ上限付近の応答性・容量・失敗回復を測り、必要なら仕様上限を調整する。

## 公開判定と記録

M7で必須受け入れ条件、型チェック、lint、ビルド、関連自動テストを通過する。原因不明の保存失敗、データ消失、画像の外部送信が残れば公開しない。任意の追加端末や将来機能は必須項目と分ける。

記録項目：実施日、コミット、環境・端末、対象ID、期待結果、実際の結果、成功／失敗／スキップ／未実行、残課題。テスト0件やプロセス起動だけを検証成功にしない。

## M2検証記録（2026-10-22）

対象：今回のM2作業ツリー。Node 24.19.0／npm 11.9.0／Linux Chromium 154.0.8037.57。本番成果物を`/workshop/`サブパスで配信して実ブラウザー操作した。

| 検証 | 結果 |
| --- | --- |
| `npm run typecheck` | 成功 |
| `npm run lint` | 成功 |
| `npm run test` | 3ファイル・42件成功（ルート12、入力欄3、画像処理27） |
| `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e` | 4ファイル・27件成功。M2新規15件＋既存12件 |
| E2E内の`npm run build -- --base=/workshop/` | 成功。TypeScriptチェックと本番ビルドを含む |
| 320pxの推し一覧・編集スクリーンショット目視 | 日本語、カード・入力・保存・削除導線、横溢れなしを確認 |

M2ブラウザーテストは以下を検証した：

- 画像なしで複数登録し、メモと名前を編集・選択して再読み込み後に復元。
- 空白名を拒否し、他の入力・既存データを保持。
- PNG／JPEG／WebPをそれぞれ取り込み、PNG Blobとして保存・再表示。
- 独自の二色JPEGにEXIF回転を付け、向き補正と長辺1,600pxへの縮小を確認。
- 画像の置換・除去、推し削除のキャンセルと確定、選択の解除。
- 非対応形式・破損画像を拒否し、既存データを保持。形式偽装・16MP／10MiB制限の境界は画像単体テストでも確認。
- 書込失敗を注入し、推し・画像の更新をまとめてロールバック。実端末の領域を満杯にする検証は行っていない。
- v1の設定がv2移行後も保持され、別タブの古いrevisionで無言上書きしない。
- 欠落・不正な画像参照でも推しの情報を救済して明示的に画像を外せる。
- 未保存のリンク移動を取り消して入力を保持し、その後のBackでも正しく確認。明示的な破棄で移動可能。
- 「推しを選ばずに進む」で選択を解除し、再読み込み後も未選択。

初回のテスト側の問題（値を含むtextareaラベルの厳密検索、非同期遷移完了前の再読込）を修正した。実装の取消リンクで履歴が重複する問題も修正し、元の操作順で再検証した。最終全27件はすべて成功。既存基盤の検証をM2の画像保存の成功と混同しない。
