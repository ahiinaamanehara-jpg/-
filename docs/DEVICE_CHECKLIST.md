## 今回Androidで確認する手順

M10の確認（実機未実行）：

- [ ] 「画面いっぱいで描く」で縦画面にCanvas・道具・保存が収まり、余白や上部を軽くなぞってもページが動かない。
- [ ] 1本指・2本指、消しゴム・取消、道具設定の色・線幅・拡大・PNGが使える。設定内だけスクロールできる。
- [ ] 「通常画面に戻る」後も線・下絵・履歴・倍率が残り、通常画面はスクロールできる。
- [ ] 縦横回転・アドレスバー伸縮・文字拡大でも操作できる。保存→再読込で絵が戻る。
- [ ] OSの保存先・TalkBack等は確認した範囲だけ記録する。iPadの使い勝手の調整は後日とする。

以下はM9までの確認手順。

M9の更新後はテスト作品で次を確認する。新しい2本指操作は実機未確認のため、成功・問題あり・未実行を分けて記録する。

1. 1本指で線を描き、2本指をキャンバス内に置いて、広げる／狭める・ひねる・ずらす。下絵と描いた線が一緒に動き、指の位置で描画・消しゴムができること。
2. 2本指から片方だけを離し、残る指を動かしても線が増えないこと。全部離してから1本指で描く。完了済みの線を取り消せることも確認する。
3. 「拡大・回転・移動」を開き、ボタンと「表示を動かす」で1本指の移動を試す。「描く」で線へ戻り、「表示を戻す」で全体表示へ戻ること。
4. 拡大・回転したまま途中保存→再読み込み。全体表示に戻って絵が保持されること。PNGを端末で開いて元の向き・大きさで下絵なし、キャンバス外はページスクロールできること。

以下はM8までの確認手順。

M8の更新後は「新しく描く」→「下絵をなぞって描く」→参考画像／端末画像を選び、指で好きな部分をなぞる。下絵の濃さを変える→「下絵を隠す」→表示へ戻す→消しゴム→取り消し→途中保存→再読み込みを試す。PNGは本人の線だけ、ZIPは下絵も含むことを確認する。なぞり描きの基本確認報告は受領済みだが、PNG・ZIP等の個別結果は未記録で、以前の押しやすさの評価へ含めない。iPadの調整は引き続き後日とする。

1. 公開更新の成功後、いつものブラウザーで[アプリ](https://ahiinaamanehara-jpg.github.io/-/)を再読み込みする。以前の推し・作品が残っていることを確認する。サイトデータは消さない。
2. テスト用の作品で、キャンバスとその下の道具が見えるところまでスクロールする。通常の文字サイズでペン・消しゴム・取り消しが横に並び、押し間違えずに切り替えられるか確認する。線を描く→消しゴム→取り消し→「途中で保存」。保存済みを確認して再読み込みし、同じ絵・色・線幅・道具へ戻れることを確認する。文字を大きくして使う場合は、折り返された道具へスクロールして届くことも確認する。
3. 推しの編集で参考画像を選び、名前・メモと一緒に保存する。端末の写真選択、ソフトキーボードを閉じる／シートをスクロールする操作で保存ボタンへ届くことを確認する。
4. 任意のヒントを開閉し、質問は「この質問をスキップ」で次へ、「振り返りを終える」で閉じることを確認する。回答なしでも絵が保存されることを確認する。
5. PNGを書き出して端末の画像表示で開く。ZIPの保存・選び直しも試す。追加復元は作品が複製されるのでテスト用データを使う。

画像の準備に時間がかかるメッセージが出た場合は、画面を閉じずに「途中で保存」や画像の選び直しを試す。描き直す際にキャンバスが動かないかも確認する。正常時に15秒待つ必要や、わざと保存を失敗させる必要はない。読み上げ・5分描画等の未実行項目は未実行のまま記録する。

## iPadで試す手順（調整再開時）

1. iPadのSafariで[すきのスケッチの公開URL](https://ahiinaamanehara-jpg.github.io/-/)を開く。利用するだけならGitHubへのログイン・Run workflow・ターミナル・アプリのインストールは不要。最新版へ更新する場合だけ[公開更新の手順](MOBILE_TEST_GUIDE.md)を行い、成功後に再読み込みする。
2. そのiPadで前から保存していたデータがあれば、推し・作品・回答が残っているか確認する。新しいテスト作品を作り、指で線を描く。対応するApple Pencilがあれば同じ道具として試せるが、筆圧機能は初期版に含めない。
3. 縦→横→縦へ回転し、絵が消えないか、指／ペンの位置と線が合うか確認する。キャンバス外でスクロール・画面拡大ができるか確認する。
4. 利用可能なマルチタスク・画面分割機能でSafariを狭くし、道具・保存・ヒントを操作する。機能名や利用可否はiPadOS・機種によって異なる。未利用なら未実行と記録する。
5. ヒントを開閉して続きを描く。任意の振り返りで「この質問をスキップ」が次の質問へ進み、「振り返りを終える」で閉じるか確認する。文章入力中にキーボードで保存ボタンが隠れても、シート内をスクロールして操作できるか確認する。
6. 「保存済み」を確認して再読み込みし、同じ絵へ戻れるか確認する。作品の棚→詳細→再開、状態変更、回答の再表示も試す。
7. PNGを書き出し、取得できなければ「画像を開く」からSafariの共有・画像保存操作を試す。端末に実際に保存され、絵だけが含まれることを画像表示アプリで確認する。
8. データ管理でバックアップZIPを「ファイル」等へ保存する。ZIPを選び直し、内容確認→キャンセルを試す。追加復元を試すと作品が複製されるため、テスト用データで行う。大切な作品は先にPNGとZIPを残す。
9. VoiceOverを使う場合はラベル・質問・保存通知・閉じる操作を確認する。外付けキーボードがあればTab移動・見えるフォーカス・Escape・閉じた後の位置を確認する。

作品は端末とブラウザーごとの保存です。同じURLを開いても、スマホの絵はiPadへ自動同期されません。スマホでZIPを書き出し、自分で選んだ方法でiPadへ渡して、iPadのアプリで追加復元してください。同じiPadでも別のブラウザーやプライベートブラウズの保存領域は別です。
