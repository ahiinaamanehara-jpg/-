## 工程の依存

M1→M2→M3→M4→M5→M6→M7の順。保存をM6まで延期すると中断復帰を確認できないため、M2で共通永続化、M3でドラフト、M4で画像保存を先行し、M6でギャラリー・回復・移出入を完成させる。M4で保存失敗を隠す仮実装は認めない。

各工程で必要なテストを追加する。M1〜M3は描画未実装を明記し、M7までは内部確認用とする。

## 技術検証の時点

- M1：対象OS・実機、ツールの固定版、静的サブパス、テストランナー。
- M2：デコード時メモリー、回転画像、形式判定、DBトランザクション。
- M4：iOSポインター取消・書出、座標変換、回転、取消履歴の予算。960px／1,600pxで比較。
- M6：ZIPライブラリーの保守性、展開制限、移行、複数タブ。大きい処理で長く停止する場合はWeb Workerを検討。
